# 📝 To-Do List Web App

A simple, clean, and responsive To-Do List web application built with vanilla JavaScript. This project allows users to manage their daily tasks in an intuitive interface with persistent storage.

## 🌟 Features

- ✅ Add new tasks
- 📋 Mark tasks as complete/incomplete
- ❌ Delete tasks
- 💾 Save tasks using `localStorage` (persists after page reload)
- 📱 Responsive design for mobile and desktop

## 🛠 Technologies Used

- **HTML5** – structure and markup
- **CSS3** – styling and layout
- **JavaScript (ES6)** – functionality and DOM manipulation
- **localStorage** – client-side data persistence
